Steep sections on cycling routes: mockups

MOCKUP with fake data. Not the app. Companion to 02-steep-sections.md. Light + dark pairs, then an e-ink frame.

Visual language, tokens and e-ink rules come from docs/design/mockups.html and docs/design/README.md. The 24 km road route below is invented: three steep sections (two climbs, one descent), detected at road-bike presets (steep up ≥ 8 %, very steep ≥ 12 %, steep down ≥ 10 %, very steep down ≥ 14 %). Colour is never the only signal: direction glyphs, brackets, hatching and labels carry the meaning too.

1. Route header: stat tile

A fifth tile appears only when there is something steep. Value = length above the "steep" threshold; red outline + red text when it contains very steep parts. Long-press shows a tooltip. Open question: five narrower tiles vs replacing one.

2. Elevation profile: steep spans + legend

The bucket-coloured fill is unchanged (GradeLegend scale). Brackets above the curve mark steep spans with their average grade; heavier line where very steep. Up = filled triangle, down = hollow triangle (violet, because blue is already the descent bucket and the map route).

3. Map: route with steep segments

Overlay features in the item's poi sub-layer (and the navigation layer while navigating), drawn over the route line. Up spans carry arrow markers, descents are hollow; one label at the steepest point. Descent spans use violet because the route itself is blue.

4. Steep sections list

A card under the chart. Tap a row: chart zooms to the span (existing range prop) and the map frames it. Tutorial page must gain the zone.

5. Navigation heads-up (in the "ahead" card)

Replaces the generic "elevation ahead" caption. Three states: approaching, inside, descent (earlier trigger, stronger wording). Warning is an outlined danger pill, not a filled block.

6. Settings

Preset defaults from the route's bicycle type (route.subtype); sliders override. Descriptions state the limits honestly (DEM, bridges and tunnels).

7. E-ink variant

No colour: tile outlined, spans hatched on the profile (diagonal = steep up, dense diagonal = very steep, cross-hatch = steep down), map spans thick black with a white arrow dash (up) or a white hollow centre (down).
