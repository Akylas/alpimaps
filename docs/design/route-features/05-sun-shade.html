Cloud cover to shadow strength (same sun, same camera)

Shadow strength follows the forecast
strength = terrainShadowStrength x clearness(t, place); clearness = DNI / clear-sky DNI, else sunshine_duration, else 1 - cloud cover. Below 8 % the SDK skips the shadow pass (free).
Clear: 100 %
Thin cloud: 45 %
Overcast: 0 % (no caster pass)
Sun disc stays drawn when clouds are not modelled by the sky (SDK has no cloud layer); the mode shows the cloud share in the chip instead.
